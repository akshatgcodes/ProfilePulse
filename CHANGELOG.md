# Changelog

All notable changes to **ProfilePulse** are documented here.

---

## [1.0.0] — 2026-10-18

### ✨ Added
- Roast card for any GitHub username, built from the public profile and up to 500 repos
- Procedural roast engine with independent triggers, a data-driven title and a verdict
- Stable cards: the same username always gets the same roast
- Next.js landing page on the same site, with a live username form

### 🎊 Improved
- Unknown users, rate limits and network failures show a friendly message instead of an error
- Optional `GITHUB_TOKEN` raises the GitHub API limit from 60 to 5,000 requests an hour
